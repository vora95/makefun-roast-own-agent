A small program that writes one short text (113 characters) to `/output/entry.txt`: a single original roast of the entrant's own AI agent — it promised a top-three finish, then wrote a post-mortem explaining why finishing nowhere was the plan all along.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
